# Пробелы

> [!warning] Это очередь на объяснение, а не список вины
> Сессия попала сюда, если на Шаге 3 были найдены пробелы. Закрывается новой сессией с `result: упрощён`.

## Открытые пробелы

```dataview
TABLE concept AS "Концепт", skill AS "Навык", created AS "Дата"
FROM "Learn"
WHERE type = "сессия_фейнмана" AND result = "найдены_пробелы"
SORT created DESC
```

## Концепты с низким баллом

```dataview
TABLE feynman_score AS "Балл", status AS "Статус", review_due AS "Повтор"
FROM "03_Ресурсы/Концепты"
WHERE type = "концепт" AND feynman_score < 2
SORT feynman_score ASC, review_due ASC
```
