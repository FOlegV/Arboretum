# Дашборд: YouTube-видео в обработке

Все клипы с `kind: видео` и `platform: youtube`, у которых `distill_layer: 1` — требуют дистилляции.

```dataview
TABLE author, platform, duration, published, distill_layer
FROM "03_Ресурсы/Источники"
WHERE kind = "видео" AND platform = "youtube"
SORT created DESC
```

## Недельный чек-лист
- [ ] Все клипы в таблице выше имеют `distill_layer ≥ 2`
- [ ] Тезисы из Слоя 4 вынесены в `03_Ресурсы/Концепты`
- [ ] Ключевые концепты имеют сессию Фейнмана в `Learn`
