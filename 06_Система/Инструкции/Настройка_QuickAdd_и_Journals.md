# Настройка QuickAdd и Journals

> [!info] Почему руками
> Конфиги этих плагинов перезаписываются приложением. Надёжнее настроить один раз через интерфейс.

## Templater

Настройки → Templater:

| Параметр | Значение |
|---|---|
| Template folder location | `06_Система/Шаблоны` |
| Trigger Templater on new file creation | выключено |
| Enable folder templates | выключено |

После изменения — перезапустить Obsidian.

## QuickAdd — 4 действия

Настройки → QuickAdd → Add Choice.

### 1. Входящее (Capture)

| Поле | Значение |
|---|---|
| Name | `Входящее` |
| Type | Capture |
| Capture To | `00_Входящие` |
| File Name Format | `{{DATE:YYYY-MM-DD}} Входящее` |
| Write to bottom of file | включено |

Формат вставки:

```markdown
- {{VALUE}}
```

## Journals

Настройки → Journals:

**Глобальные настройки:**
| Параметр | Значение |
|---|---|
| Week start / First week of year | Пресет `iso-8601` (понедельник, неделя с первым четвергом января) |
| Apply week configuration to all dates in vault | включено |
| Root folder | `04_Журнал` |

**Три журнала:**

| Журнал | Тип | Папка (относительно root) | Формат даты | Auto-create today |
|---|---|---|---|---|
| Дневной | `day` | `Дневные` | `YYYY-MM-DD` | включено |
| Недельный | `week` | `Недельные` | `YYYY-[W]w` | выключено |
| Месячный | `month` | `Месячные` | `YYYY-MM` | выключено |

Шаблоны подключаются в настройках каждого журнала через `template path`:
- Дневной → `06_Система/Шаблоны/Шаблон — Дневная заметка.md`
- Недельный → `06_Система/Шаблоны/Шаблон — Недельный обзор.md`
- Месячный → `06_Система/Шаблоны/Шаблон — Месячный обзор.md`

Проверить, что нет предупреждения «Colliding journal settings».

Ежедневную заметку держать простой: два чекбокса из [[Регламент_ежедневный]] (Входящее разобрано / Очередь повторений пройдена) и ссылки на дашборды. DataviewJS внутри embed не рендерится — давать ссылку `[[Очередь_повторений]]`, а не `![[...]]`.

## Проверка

1. `Ctrl+P` → `QuickAdd: Новый концепт`
2. Ввести название — файл появляется в `03_Ресурсы/Концепты`
3. Проверить, что `created` и `review_due` заполнены датой, без кавычек
