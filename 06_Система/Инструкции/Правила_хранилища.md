# Правила хранилища

> [!important] Одно правило важнее десяти заметок
> Если сомневаешься, куда положить файл — держи правило ниже.

## 1. Один тип заметки — одна папка

| Тип | Папка | `type` |
|---|---|---|
| Концепт | `03_Ресурсы/Концепты` | `концепт` |
| Карта (MOC) | `03_Ресурсы/Карты` | `карта` |
| Источник | `03_Ресурсы/Источники` | `источник` |
| Сессия Фейнмана | `Learn` | `сессия_фейнмана` |
| Навык | `02_Области/Навыки` | `навык` |
| Проект | `01_Проекты` | `проект` |
| Входящее | `00_Входящие` | — |
| Журналы | `04_Журнал/{Дневные,Недельные,Месячные}` | — |

Концепт **не** живёт в проекте. Проект ссылается на концепт, а не хранит его.

## 2. Папка = статус действенности, а не тема

- `00_Входящие` — не разобрано.
- `01_Проекты` — есть дедлайн и результат.
- `02_Области` — поддерживается постоянно, без дедлайна.
- `03_Ресурсы` — знание на будущее.

Тема задаётся тегом или ссылкой на карту, а не папкой.

## 3. Ключи английские, значения русские

```yaml
type: концепт
status: растёт
```

Не смешивать: `тип: концепт` — запрещено.

## 4. Даты — без кавычек

```yaml
review_due: 2026-11-10      # верно
review_due: "2026-11-10"    # неверно — ломает очередь повторений
```

## 5. Не больше 10 полей

Всё, что можно вычислить, вычисляется запросом: число сессий, средний балл, дата последнего касания.

## 6. Ссылки, а не текст

Связи оформляются как `[[Ссылка]]`, а не как текст в поле. Это делает backlinks рабочими.

## 7. Теги

- Первый тег описывает **тип/навык**: `концепт`, `сессия`, `проект`, `навык`, `источник`, `карта`, `ежедневник`, `задача`.
- Второй тег описывает **домен**: `domain/философия`, `domain/здоровье`, `domain/видео`, `domain/тестирование`, `domain/продуктивность`, `domain/навигация`.
- Тип описывает **форму**: `type: концепт`.
- Не дублировать: если есть `type: концепт`, тег `концепт` нужен только для быстрых фильтров в поиске.

## 8. Именование файлов

- Концепт: существительное в именительном падеже — `Асинхронность.md`.
- Сессия: `YYYY-MM-DD — Концепт.md`.
- Навык: `Python.md`, `Статистика.md`.
- Источник: `Автор — Название.md`.

## 9. Проекты

Проект считается завершённым, когда в frontmatter стоит:

```yaml
type: проект
status: завершён
skill: "[[Навык]]"
```

Только такие проекты учитываются в гейтах древа навыков.

## 10. Вложения

- Изображения — `06_Система/Вложения/Изображения`
- PDF — `06_Система/Вложения/PDF`
- Холсты Excalidraw — `06_Система/Вложения/Холсты`
- В Obsidian: Files & Links → Default location for new attachments → `06_Система/Вложения`

## 11. Бэкап до массовых правок

Перед Tag Wrangler, переименованием папок и правкой frontmatter пачкой — коммит в Git (плагин Obsidian Git) или копия хранилища.

## 11. YouTube-клипы из Web Clipper

- Клипы прилетают в `00_Входящие`. Это временная площадка, не итоговое хранилище.
- При разборе входящего создайте источник через QuickAdd `YouTube-источник` в папку `03_Ресурсы/Источники`.
- Имя файла: `Канал — Название ролика.md` (без лишних слов).
- Тип: `источник`, `kind: видео`, `platform: youtube`.
- Не более 10 полей frontmatter. Тайм-коды вводите вручную в Слое 1.
- Поле `distill_layer` показывает этап обработки: 1 = только клип, 4 = готово к извлечению концептов.
