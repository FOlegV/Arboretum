# Еженедельный регламент — 4 блока

> [!important] Общее время: 20–40 минут
> Выполнять в один и тот же день недели. Пропуск недели — не катастрофа, пропуск месяца — конец системы.

## Блок 1. Бэкап — 5 минут

- [ ] Закоммитить хранилище через Obsidian Git (или скопировать папку)

**Обязательно до Блока 2.** Tag Wrangler меняет файлы пачкой и откатывается только через историю.

## Блок 2. Гигиена тегов — 5–10 минут

- [ ] Открыть Tag Wrangler
- [ ] Найти теги с одной-двумя заметками — слить или удалить
- [ ] Проверить опечатки: `#pythno` → `#python`
- [ ] Убедиться, что темы не дублируются с `type`

## Блок 3. Древо навыков — 10 минут

- [ ] Открыть [[Обзор_древа]]
- [ ] Для каждого навыка посмотреть «Следующий гейт»
- [ ] Если гейт закрыт по данным — поднять `level` в заметке навыка
- [ ] Если навык застрял на одном уровне 3+ недели — либо закрыть его (`status: закрыт`), либо запланировать конкретное действие

Уровни 4–5 ставятся только вручную и только при наличии артефакта.

## Блок 4. Очереди и один артефакт — 5–10 минут

- [ ] Открыть [[Пробелы]] — выбрать один пробел
- [ ] Открыть [[Очередь_повторений]] — проверить, нет ли концептов, просроченных больше чем на 14 дней
- [ ] Создать **один** артефакт за неделю: сессия Фейнмана, резюме источника или новый концепт

Один артефакт в неделю — это 52 в год. Этого достаточно.

## Чек-лист недели

```markdown
- [ ] Бэкап
- [ ] Теги
- [ ] Древо
- [ ] Очереди
- [ ] Один артефакт: 
```
