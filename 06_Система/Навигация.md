# Навигация

Точка входа в систему. Всё, что нужно ежедневно, — в первой секции.

## Каждый день

- [[Очередь_повторений]] — что просрочено и две кнопки оценки
- [[Регламент_ежедневный]] — 5 минут на входящее, 5 на повторение

## Каждую неделю

- [[Регламент_еженедельный]] — 4 блока: бэкап → теги → древо → очереди
- [[Обзор_древа]] — уровни навыков, автогейты, следующий шаг
- [[Пробелы]] — где объяснение провалилось
- [[Видео_в_обработке]] — YouTube-клипы, требующие дистилляции

## Где что лежит

| Папка | Что внутри |
|---|---|
| `00_Входящие` | Сырое, необработанное. Разбирается ежедневно |
| `01_Проекты` | Есть срок и результат. Закрывается → `status: завершён` |
| `02_Области` | Действующие зоны ответственности |
| `02_Области/Навыки` | Узлы Skill Tree |
| `03_Ресурсы/Концепты` | Атомы знания. Только здесь |
| `03_Ресурсы/Карты` | MOC — карты содержания |
| `03_Ресурсы/Источники` | Книги, статьи, видео, курсы |
| `Learn` | Сессии Фейнмана. Только здесь |
| `04_Журнал/Дневные` | Дневные заметки Journals (авто-создание при открытии) |
| `04_Журнал/Недельные` | Недельные обзоры |
| `04_Журнал/Месячные` | Месячные обзоры |
| `06_Система` | Шаблоны, дашборды, инструкции |
| `06_Система/Вложения` | Изображения, PDF, холсты Excalidraw |

## Быстрый старт

1. Открой [[Очередь_повторений]].
2. Если пусто — создай концепт из источника и проведи сессию Фейнмана.
3. Раз в неделю — [[Регламент_еженедельный]].
