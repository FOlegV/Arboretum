# Начните работу с TaskNotes

Эта заметка — краткое знакомство с TaskNotes в вашем хранилище. Пройдите шаги прямо здесь, а затем оставьте заметку для справки или удалите, когда она больше не понадобится.

TaskNotes особенно удобен, когда три действия связаны между собой:

1. Быстро записать задачу.
2. Сохранить её как обычную заметку Markdown.
3. Просматривать задачи в представлениях Bases.

## Перед началом

- [ ] Включите встроенный плагин Obsidian **Bases**.
- [ ] Убедитесь, что TaskNotes создал файлы `.base` по умолчанию в `TaskNotes/Views/`.
- [ ] Откройте палитру команд и выполните **TaskNotes: Открыть представление задач**.

TaskNotes автоматически создаёт недостающие файлы `.base` по умолчанию при запуске, если включена настройка **Автоматически создавать файлы по умолчанию**. Если файлов нет, выберите **Настройки -> TaskNotes -> Общие -> Представления и файлы Bases -> Создать файлы**.

## 1. Создайте задачу из палитры команд

Выполните **TaskNotes: Создать новую задачу** и добавьте реальную задачу, которую планируете выполнить в ближайшее время.

Например, с таким названием:

```text
Review my TaskNotes setup tomorrow #admin
```

После сохранения TaskNotes создаст заметку Markdown для этой задачи. Откройте её и посмотрите на свойства YAML в начале. Bases использует их для фильтрации, сортировки, группировки и размещения в календаре.

## 2. Преобразуйте задачи в тексте в TaskNotes

Флажки ниже — обычные задачи Markdown. Преобразуйте каждую в заметку задачи через действие в строке или палитру команд.

- [ ] Создать задачу TaskNotes со сроком завтра #admin
- [ ] Запланировать 20-минутную задачу на следующий понедельник #planning
- [ ] Создать задачу, связанную с заметкой активного проекта

После преобразования обратите внимание:

- Исходная строка может остаться в этой заметке как контекст.
- Сама задача теперь хранится в отдельной заметке Markdown и появляется в представлениях TaskNotes.
- Преобразованная строка ссылается на заметку задачи. Щёлкните по ссылке правой кнопкой мыши, чтобы открыть меню задачи, и попробуйте изменить статус, приоритет, срок выполнения, запланированную дату или проект.

## 4. Меняйте только то, что мешает

Для начала достаточно настроек по умолчанию. Вернитесь к ним, когда поймёте, что нужно изменить:

- Если файлы задач сохраняются не там, проверьте **Настройки -> TaskNotes -> Общие**.
- Если задачи, преобразованные из текста, должны создаваться в другом месте, проверьте **Настройки -> TaskNotes -> Настройки задач в тексте**.
- Если модальное окно задачи показывает слишком много или мало полей, проверьте **Настройки -> TaskNotes -> Поля модального окна**.
- Если в хранилище используются другие имена свойств, статусы, приоритеты или пользовательские поля, проверьте **Настройки -> TaskNotes -> Свойства задачи**.

## 5. Настройте под себя

Попробуйте добавить в задачу пользовательское свойство, например `energy`, `client` или `area`. Поскольку задачи — это заметки Markdown, пользовательские свойства можно применять в Bases без отдельной базы данных задач.

## 6. Контекстные представления

Представления Bases можно встраивать в ежедневные заметки, заметки проектов, встреч или задач. Расширенные фильтры Bases могут учитывать текущую заметку, чтобы представление показывало связанные с ней задачи.

TaskNotes использует такой подход в виджете связей заметок задач. Когда захотите настроить представления, посмотрите примеры в документации TaskNotes.

Что ещё попробовать:

- Создайте копию `TaskNotes/Views/tasks-default.base` и настройте представление для одного проекта.
- Добавьте в представление Bases группировку, например по статусу или приоритету.
- Добавьте фильтр для задач со сроком выполнения на этой неделе.
- Свяжите задачу с заметкой проекта и найдите упоминания через обратные ссылки.

## Дополнительная помощь и расширения

- Документация: [tasknotes.dev](https://tasknotes.dev/)
- Проблемы и ошибки: [создайте обращение на GitHub](https://github.com/callumalpass/tasknotes/issues)
- Сопутствующие плагины:
  - [Canvas Bases](https://tasknotes.dev/companion-plugins/canvas-bases/) добавляет доски в стиле Canvas и снимки JSON Canvas для представлений Bases, а также необязательные значки TaskNotes, действия и связи.
  - [TaskNotes Workflows](https://tasknotes.dev/companion-plugins/tasknotes-workflows/) добавляет автоматизацию событий, расписаний, ручных команд и действий с задачами TaskNotes на основе Markdown.

## Готово

Главное: задачи — это заметки, свойства позволяют их искать, а Bases превращает их в представления.
