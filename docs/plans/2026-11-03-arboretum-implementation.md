# План внедрения архитектуры Arboretum

**Дата:** 2026-11-03
**Статус:** в работе
**Источник:** `Ниже — детальная архитектура и поша.md`

## Цель

Превратить хранилище в систему, где знание не просто складывается, а проверяется (метод Фейнмана), закрепляется (интервальные повторения) и связывается с навыками (Skill Tree).

## Принятые решения

| Вопрос | Решение |
|---|---|
| Язык ключей frontmatter | Английские ключи, русские значения |
| Схема концепта | 10 полей, не больше |
| MOC-принадлежность | Через backlinks, отдельного поля нет |
| Производные метрики | Считаются запросами, не хранятся |
| Алгоритм повторений | Упрощённый SM-2: интервал × 2.5, потолок 180 дней |
| Уровни навыков 4–5 | Присваиваются вручную |
| Конфиги QuickAdd/Journals | Пишутся руками через GUI, не файлом |

## Схема данных

### Концепт

```yaml
type: концепт
status: семя | растёт | вечнозелёный
created: 2026-11-03
source: "[[Источник]]"
skill: "[[Навык]]"
feynman_score: 0-3
review: true
review_due: 2026-11-10
review_interval: 1
tags: [концепт]
```

### Навык

```yaml
type: навык
skill_id: python-async
level: 0-5
status: закрыт | доступен | изучается | освоен | мастер
parent: "[[Навык]]"
requires: ["[[Навык]]"]
tags: [навык]
```

### Сессия Фейнмана

```yaml
type: сессия_фейнмана
concept: "[[Концепт]]"
skill: "[[Навык]]"
result: не_начат | объяснён | найдены_пробелы | упрощён
score: 0-3
created: 2026-11-03
tags: [сессия]
```

### Источник

```yaml
type: источник
author: 
url: 
kind: книга | статья | видео | курс
distill_layer: 1
created: 2026-11-03
tags: [источник]
```
